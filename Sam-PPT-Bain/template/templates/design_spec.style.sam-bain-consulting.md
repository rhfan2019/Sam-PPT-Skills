# Sam 蓝红咨询构图 — Style Specification

> Method and design defaults only. No project communication contract, brand identity, page structure, or SVG prototypes.

## I. Style Overview

| Property | Value |
|---|---|
| Style Name | Sam 蓝红咨询构图 |
| Best Fit | 中文行业研究、咨询白皮书、经营诊断与方案汇报中需要"一页讲清一个判断并给出证据"的正文页，既用于讲解也用于会后精读 |

## II. Communication Method

- **Preferred Mode**: pyramid
- **Argument Flow**: 先确定全篇要回答的问题和总答案，再拆成若干支撑论点，每个论点落到一页；保持"总答案 → 支撑论点 → 页面结论 → 证据"的可追溯链。顺序服从当前项目，不套固定页序。
- **Page Message Discipline**: 每页标题必须是结论句（不是话题词）；页面若使用论点条，论点条写本页的 so-what，与标题互补、不重复标题措辞。区块标签只说明左右两侧各讲什么（≤ 8 字）。一页只回答一个问题。
- **Claim Discipline**: 事实、推算、判断、建议分开表述。只使用大纲/资料中存在的事实，**不替原文添加修饰或新事实**；由原始数据推算出的数字（同比、份额、差值、转化率、均值、倍数）可以用来提高信息密度，但必须标明是推算值，并在交付时逐条列出供核实。

## III. Page Role Vocabulary

| Role | Communication Job | Evidence Obligation | Composition Tendency |
|---|---|---|---|
| 趋势分阶段 | 说明一个指标随时间如何演进、分几段、拐点在哪 | 原始序列逐点标注；阶段划分与增速必须可由数据算出 | 左侧主图：柱 + 折线（折线浮在柱上方）+ 阶段底色带 + 指向具体数据点的标注气泡 + 与类目对齐的同比胶囊行；右侧阶段诊断链（图标圆 + 阶段名 + 年份 + 右箭头 + 标签框 + 两条说明，弧形箭头串联）；右下证据框放本页未出现的推算指标；底部"A ⇄ B"式框架条 |
| 转化漏斗 | 指出流程中最弱的一环 | 各阶段占比、相邻转化率与流失率由数据算出，最弱环节自动标红 | 中央立体切面漏斗（每层左右两半深浅不同，最弱层砖红）；左翼阶段定义（右对齐标题 + 说明 + 图标圆，圆点虚线连到漏斗层）；右翼转化诊断（转化率圆 + 环节名 + 右箭头 + 流失标签，弧形箭头串联）；远端关键指标证据框 + 剩余人数小图；底部框架条 |
| 中心辐射 | 说明一个核心如何由多个部分共同支撑 | 每个部分给出一个代表性指标或特征，不编造 | 中央核心圆 + 同心虚线环 + 4–6 个节点圆（带编号徽章），两翼为无卡片条目（编号 + 名称 + 指标 + 分隔线 + 分组标签 + 说明），圆点虚线从条目连到节点；两翼下方各一个证据模块（结构条 / 小条形对比）；底部框架条 |
| 左右对比 | 帮读者在两个选项之间做判断 | 对比维度、单位、口径一致；"优"的判定规则写明 | 两侧语义配色（左蓝右红），中间对照轴；优劣势、适用场景、关键指标镜像条形 |
| 矩阵 / 定位 | 用两个维度切出不同情形并给出对应选择 | 维度定义清楚；落入各象限的依据可追溯 | 2×2 主图 + 轴标签 + 被强调的一行/一列底色带；右侧核心数字 + 两条判断 |
| 结构与层级 | 说明由低到高或由内到外的层次 | 每层给出决定性特征 | 立体分层主图（金字塔、价值链曲线等）+ 编号说明行 + 指示难度/方向的箭头 |
| 结论与建议 | 把全篇判断收束为可执行的举措 | 每项建议对应前文证据 | 战略屋或举措矩阵：愿景 + 支柱 + 基础，支柱带总结标签 |

## IV. Evidence & Data Expression

- **Argument Trace**: 每页证据要能指回本页结论；证据框只放本页正文没出现过的新信息（推算值、跨页引用），不重复图上已有数字。
- **Charts**: 图表优先用 PowerPoint 原生可编辑图表或原生形状。每个数据点直接标值，能省则省坐标轴与网格线；用阶段底色带、参考线、标注气泡（尖角落在具体数据点上）和同比/份额胶囊行讲故事；最关键的变化用砖红标出。柱线组合时折线浮在柱子上方，避免标签互相遮挡。
- **Tables**: 列与行由比较逻辑决定；焦点列用砖红框突出，关键单元格红色加粗；表头深色、首列浅蓝底。
- **Sources**: 页脚左下写免责声明或数据来源；示例数据必须注明"示例数据"。推算值在交付说明中逐条列出。
- **Native Editability**: 文字、图表、表格、形状全部保持可编辑；不使用截图替代图表。

## V. Visual System Defaults

- **Preferred Visual Style**: custom
- **Visual Style Behavior**: 白底正文页，海军蓝为主色、砖红为强调与"另一侧"语义。页面由五区构成：论点条 → 左右区块标签 → 中央主图 + 两翼 → 远端证据框 → 底部"A ⇄ B"框架条（两组虚线浅色框 + 上下两条反向箭头 + 两端图标与标签）。**去卡片化**：两翼条目浮在版面上，用对齐、圆点虚线、弧形箭头、右箭头把内容连成一个系统；卡片只留给区块标签、标签框和证据框。允许元素有意交叠（徽章压在节点边、图标圆压在线端）。
- **Composition**: 内容区以标题线两端为左右边界，任何元素不得越界，全宽元素两端贴齐边界。同一行的标题、箭头、标签框、说明共用一条中线；上下相邻的列左右边缘对齐。中央主图占据页面视觉重心，两翼宽度相当，证据列贴右边界。
- **Density**: 文档级密度。标题 37 px，论点条约 27 px，区块标签 24 px，条目标题约 17 px（粗体），正文/说明约 12.7–14 px，证据框单位与注释约 10.7 px。每条信息至少三层（图标圆 + 粗体标题 + 说明，常再加标签框）。空白只出现在模块之间，不留整块空区。
- **Decoration**: 同色相渐变（海军蓝 #16365F → #2E5A94，砖红 #8E2B1D → #C0503E）用于标题条、节点圆、主图分层；柔和阴影只给浮起的圆和证据元素；虚线用于连接线、证据框和框架条格子；弧形箭头串联诊断链。避免与内容无关的装饰图形。
- **Color Behavior**: 左侧/用户侧/现状用蓝系，右侧/策略侧/判断用红系，颜色表达"属于哪一侧"而不是装饰；红色面积约不超过全页 20%；深色底上不放浅色字。已安装的 Deck 身份（sam-bain）提供确切色值。
- **Typography Character**: 一个无衬线家族的多个字重：标题最粗、标签中等、正文常规、数字粗体；层级靠字重、字号与对齐，而不是靠框。

## VI. Image & Icon Direction

- **Image Usage**: 图片只在提供证据或必要语境时使用；抠图类物体（如产品）可压在主图或核心圆下方增加层次；照片类做低不透明度、边缘羽化的背景，不抢主图。
- **Image Treatment**: 背景照片四周渐隐到白底；不在图片里放合成文字。
- **Icon Treatment**: 一页只用一个图标家族，统一着色：节点圆、条目图标圆内放白色图标，标签旁的小图标用主色或强调色；图标只用于说明角色、状态或关系。

## VII. Review Focus

- 所有内容元素都在标题线两端（35.93 / 1244.07 px）之内，全宽元素两端贴齐。
- 同一行元素共用一条中线，相邻列边缘对齐；无文字溢出、遮挡或数字与单位分行。
- 标题是结论句，论点条与标题互补；同一数字在一页上只出现一次。
- 每页能看到五区构图中的主要部分，信息密度足够、没有整块空区。
- 推算数字已标明并在交付说明中列出。
