# 页面做法（ppt-master SVG 版）

> 画布 1280×720（ppt169）。所有坐标都是 SVG 像素。页框与 slot 由模板提供，正文区几何全部 Slide-local。
> 起点：有同类页型时，打开 `examples/nev-case/pilot-pages/` 里的试点页 SVG，借用它的 `<defs>`、页框与构件写法；文字、数据、图片一律来自本次大纲，不搬试点页的内容。

## 二、常用构件（尺寸取自已验收试点页）

**区块标签**：`<rect>` 高 40，左侧 #C4D7F1、右侧 #F4D1CC，文字 OPPOSans M 22 #0D0D0D 居中，基线 = 顶 + 28。宽度与下方栏同宽或按字数（每字约 24 px + 左右各 24 px）。放在正文区顶部 y 166。

**图标圆（节点）**：r 23，`fill="url(#nodeNavy)"` 或 `nodeRed`，白描边 2，`filter="url(#softShadow)"`；圆心放白色图标 22×22（`<use data-icon="chunk-filled/xxx" fill="#FFFFFF">`）。

**诊断行**：图标圆 → 条目标题（OPPOSans M 20，可带 13.33 灰色年份 tspan）→ 两行说明（R 13.33 #404040，行距 18）→ `rightArrow` 预设（30×20）→ 标签框（高 30，浅蓝/浅粉底，M 14.67 居中，右缘贴 1244.07）。行与行之间用砖红弧形箭头 `<path d="M x y Q ...">` + `marker-end` 串联。行距 88。

**证据框**：`<rect>` 高 66，`fill="#F4D1CC" fill-opacity="0.18"`，砖红 1.2 虚线 `4,3`；大数字 OPPOSans B 24 #A23424 + 12 px 单位 tspan；下方 10.67 灰色说明；右侧 `upArrow` / `downArrow` 预设 26×46。三个一组时等宽排开，最右一个贴 1244.07。

**底部框架条**（y 578–658）：顶部一条 #BFBFBF 细线贴两端 → 左端图标 + "A"（M 21.33 蓝）→ 两个浅蓝虚线框（180×54，`fill-opacity 0.35`，描边 #8EA9CF `4,3`，两行 M 14.67）→ 中间上下两条反向箭头（蓝向右、红向左，各配 12 px 说明）→ 两个浅粉虚线框 → 右端 "B" + 图标（贴 1244.07）。框里的词必须来自大纲本页。

**标注气泡**：`wedgeRectCallout` 预设，砖红底白字，尖角坐标按数据点计算（`data-pptx-av-adj1/2`）。

**胶囊行**：与柱子中心对齐的圆角小框（高 20，12 px 字），≥ 50% 的增速用砖红底白字，其余浅色底。

**圆点虚线连接**：`stroke-dasharray="1.5,4" stroke-linecap="round"`，从条目连到主图节点，端点放 r 3 小圆点。

**预设形状**：箭头、气泡、梯形等用 `preset_shape_svg.py render-batch` 生成片段后原样粘贴（不要手改 path），并放在一个带 `data-pptx-bounds` 的父 `<g>` 里。

## 三、页型做法

每页写之前先决定：页型、主图、两翼各讲什么、证据框放哪几个推算值、框架条的 A ⇄ B。

| 页型（大纲"建议呈现"） | 做法 |
|---|---|
| 封面 | `01_cover`：标签 → 标题（48 px，最多两行，按语义断行）→ 副标题 → 机构 / 日期 |
| 目录 | `02_toc`：每章一行，"01" 砖红大号编号 + 章节名（冒号前）+ 说明（冒号后）+ 虚线分隔；行高 = 可用高度 ÷ 章节数 |
| 柱 + 折线趋势（试点页 `trend-phases`） | 左：柱（海军蓝渐变）+ 折线（砖红，浮在柱上方）+ 阶段底色带 + 标注气泡 + 同比胶囊行；右：阶段诊断三行 + 证据框；底部框架条 |
| 漏斗（试点页 `funnel`） | 中：立体切面漏斗（每层左右两半深浅不同，最弱环节砖红）；左翼：阶段定义 + 图标圆 + 圆点虚线连到层；右翼：转化率圆 + 环节名 + 流失标签 + 弧形箭头；远端：关键指标证据框 + 剩余人数小图 |
| 中心辐射（试点页 `hub`） | 中：核心圆 + 同心虚线环 + 4–6 个带编号徽章的节点 + 压在下方的实物图；两翼：无卡片条目（编号 + 名称 + 指标 + 分隔线 + 标签 + 说明），圆点虚线连到节点；两翼下各一个证据模块 |
| 百分比圆环 ×N | 横排 N 个圆环（外环 #E6ECF5 底 + 海军蓝/砖红弧，最关键的一个用砖红），环内大数字；环下指标名 + 一句括注；底部一条全宽"结论"框架条把几个指标收束成一句判断 |
| 左右双图（堆积柱 + 堆积面积） | 栏宽按类目数分配，栏间细竖线；系列直接标注在末端；每栏下方 10.67 px 微型说明放大纲的"注"；份额变化做成胶囊行 |
| 数据看板 | 顶部 4 个 KPI（大数字 + 单位 + 同比胶囊 + 图标圆），下方 3 个小图按信息量分栏；区块标签标出"规模""结构""趋势"等，但词必须来自大纲 |
| 左右对比 | 左蓝右红两翼条目逐行对齐，中间一列对照指标（镜像条形 + 数值），行间浅灰虚线、栏间细竖线，不铺底色 |
| 表格 + 发现 | 原生形状表格：表头海军蓝白字，首列浅蓝底；焦点列砖红细框；右侧发现栏（编号 + 一句话）贴右边界 |
| 雷达 | 六边形网格（同心虚线）+ 三条半透明多边形；右侧发现栏；每个顶点标维度名 |
| 2×2 矩阵 | 主图四象限（被强调的一格用浅色底带）+ 轴名放两端"低 / 高"；右侧核心数字（如约 45%）+ 判断 |
| 蝴蝶图 | 中轴放因素名，左右对称条形（左蓝右红），差值最大的两项砖红强调；条形末端标值 |
| 人物画像 | 左：人物/场景照片或图标 + 名称 + 标签语 + 标签胶囊；中：基础属性与核心诉求；右：TGI 横条（100 为参考线）；底部引号块放用户原话 |
| 气泡图 | 坐标轴（价格 × 月销）+ 三色系气泡（面积 ∝ 续航）+ 价格带底色带（如 15 万以下、25–35 万）；气泡就近标注车型 |
| 微笑曲线 | 平滑曲线 + 七个节点（高附加值两端砖红）+ 每节点下方说明；左右两端区块标签 |
| 金字塔 | 自上而下 5 层立体切面（左右两半深浅不同），右侧编号说明行逐层对齐，左侧一条"越往上越难复制"的竖向箭头 |
| 时间轴 | 一条主轴 + 年份节点，重点节点砖红并放大；说明上下交错，避免拥挤 |
| 多列卡片 | 5 列等宽，每列：品牌名 → 路线胶囊 → 大数字（年销）→ 三条要点；列间细竖线，不画卡片阴影 |
| 战略屋 | 屋顶（砖红/海军蓝渐变三角或梯形，写目标）→ 4 根支柱（标题 + 要点）→ 地基（通栏）；支柱与地基两端贴齐边界 |

## 四、技术要点（ppt-master 约束）

- 根节点带四个 `data-pptx-master/-layout` 属性，与所用原型一致；页框原子与 slot 原样保留在最前面，正文 `<g>` 在后。
- 每个根层内容 `<g id>` 必须有 `data-pptx-bounds`，根层组之间重叠不超过 1 px（slot 组与 `data-pptx-role="decoration"` 组除外）。把同属一个视觉单元的东西放进同一个组。
- 不用 `style` / `class` / `mask`；箭头用 `marker-end` 挂在 `line` / `path` 上。
- 图表绘图区写标记：`<!-- chart-plot-area: object=<key> | x_min,y_min,x_max,y_max -->` 放在 `<g id="<key>-chartArea">` 里；柱高、折线点用 `svg_position_calculator.py` 核对。
- 文本统一 `lang="zh-CN"`（写在根 `<svg>`）。
- ppt-master 不认识 OPPOSans 的中文槽位，导出后由 `fix_cjk_fonts.py` 统一改回同字重的 OPPOSans（`finish` 自动执行）。
