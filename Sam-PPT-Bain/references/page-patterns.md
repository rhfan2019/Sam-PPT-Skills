# 页面做法（ppt-master SVG 版）

> 画布 1280×720（ppt169）。所有坐标都是 SVG 像素。页框与 slot 由模板提供，正文区几何全部 Slide-local。
> 本文件只放通用做法，不含任何案例内容；文字、数据一律来自本次大纲。

宽度按 `new` 输出的校准表计算（中文字数 ÷ 每 100 px 字数 × 100），先写句子再定框，留 5% 余量。英雄数字用校准表的 `hero` 行（56 px B），其他字号按比例换算；数字比汉字估算更容易偏宽，旁边的标签放在数字上方或下方，不与数字同行并排。

## 二、常用构件

**栏面板（分区的默认做法）**：每个大区一块整栏浅底 `<rect>`（左/现状侧 #EEF3FA，右/判断侧 #FBEFED，无描边或 1 px 同色系描边），从区块标签 / 栏头条下沿一直铺到该区内容底部（通常 y 664–672）；栏间留 20–30 px 白缝，不再画细竖线。面板内部的子模块直接浮在面板上，不再套卡片。

**栏头条（深色实块）**：面板顶部一条 `<rect>` 高 36–40，海军蓝 #1C4274 或砖红 #A23424 实底，白字 OPPOSans M 20–22 居中，与面板同宽。一页里栏头条和浅色区块标签二选一，不混用；页面需要深色实块时优先用栏头条。

**英雄数字**：OPPOSans B 48–64，海军蓝或砖红，单位 tspan 18–21 px，指标名 M 14.67 放在数字下方（或上方）；每页 1–2 个，放在主视觉旁或证据栏顶端，是全页最大的字。可以压在主视觉边缘（跨界）。页面上的数字都是并列或重复关系、挑不出 1–2 个主角时，不硬选：改用英雄关键词（rules.md 二.9），或把这组并列数字做成一排统一 40 px 的数字行。

**贯穿箭头带**：一条全宽或跨两栏的 `homePlate` / `rightArrow` 预设（高 36–48，海军蓝或蓝→红两段），带上写阶段或时间（白字 M 18.67）；用来收束全页或把两栏连成一个时间轴，代替细线框架条。

**区块标签**：`<rect>` 高 40，左侧 #C4D7F1、右侧 #F4D1CC，文字 OPPOSans M 22 #0D0D0D 居中，基线 = 顶 + 28。宽度与下方栏同宽或按字数（每字约 24 px + 左右各 24 px）。放在正文区顶部 y 166。

**图标圆（节点）**：r 23，`fill="url(#nodeNavy)"` 或 `nodeRed`，白描边 2，`filter="url(#softShadow)"`；圆心放白色图标 22×22（`<use data-icon="chunk-filled/xxx" fill="#FFFFFF">`）。
- **什么时候用图标**：3 个以上并列的条目、卡片、栏头、结果项，每项配一个图标圆；流程节点、核心圆可以用图标代替文字以外的装饰。一套 deck 只用一个图标库（默认 `chunk-filled`），图标名先在插件图标目录里查到再用。
- 一页完全不用图标时，在交付说明里写一句原因（如"本页是纯数据图"）。

**诊断行**：图标圆 → 条目标题（OPPOSans M 20，可带 13.33 灰色年份 tspan）→ 两行说明（R 13.33 #404040，行距 18）→ `rightArrow` 预设（30×20）→ 标签框（高 30，浅蓝/浅粉底，M 14.67 居中，右缘贴 1244.07）。行与行之间用砖红弧形箭头 `<path d="M x y Q ...">` + `marker-end` 串联。行距 88。

**证据框**：`<rect>` 高 72–80，`fill="#F4D1CC" fill-opacity="0.18"`，砖红 1.2 虚线 `4,3`（蓝侧用 #8EA9CF 虚线 + #C4D7F1 底）；大数字 OPPOSans B 28–32 #A23424 + 14.67 px 单位 tspan；下方 13.33 #595959 指标名（只写指标名，不写算式）；右侧 `upArrow` / `downArrow` 预设 26×46。三个一组时等宽排开，最右一个贴 1244.07。

**底部框架条**（y 578–658）：顶部一条 #BFBFBF 细线贴两端 → 左端图标 + "A"（M 21.33 蓝）→ 两个浅蓝虚线框（180×54，`fill-opacity 0.35`，描边 #8EA9CF `4,3`，两行 M 14.67）→ 中间上下两条反向箭头（蓝向右、红向左，各配 12 px 说明）→ 两个浅粉虚线框 → 右端 "B" + 图标（贴 1244.07）。框里的词必须来自大纲本页。

**标注气泡**：`wedgeRectCallout` 预设，砖红底白字，尖角坐标按数据点计算（`data-pptx-av-adj1/2`）。

**胶囊行**：与柱子中心对齐的圆角小框（高 20，12 px 字），≥ 50% 的增速用砖红底白字，其余浅色底。

**圆点虚线连接**：`stroke-dasharray="1.5,4" stroke-linecap="round"`，从条目连到主图节点，端点放 r 3 小圆点。

**运算符（+ / × / =）**：放在它连接的两组内容正中间的空隙里，与两组的中线对齐；字号 22–28 或用 `mathPlus` / `mathMultiply` / `mathEqual` 预设；不能单独放在页面边缘或某一组的角上。

**预设形状**：箭头、气泡、梯形等用 `preset_shape_svg.py render-batch` 生成片段后原样粘贴（不要手改 path），并放在一个带 `data-pptx-bounds` 的父 `<g>` 里。

## 三、页型做法（数据页）

每页写之前先决定：页型、**主视觉是什么、占多大（正文区 45–60%）**、页面切成哪 2–3 个色块大区（面板 / 栏头条）、深色实块放在哪、英雄数字是哪 1–2 个、两翼各讲什么、各模块怎样连到主视觉（第三C节）、证据框放哪几个推算值、底部用框架条还是贯穿箭头带收束。写完对照 rules.md 二.7–11。

**图内数据标签**：
- 柱、点只标数值本身（10.67–13.33），合计、末点、关键点可加粗放大；系列名直接标在末端；不写"柱：… 线：…"式图例句。
- **峰值、拐点、重点数据要直接标在图上**：节点旁标出数值并用砖红（圆点放大或加标注气泡）；旁边的大数字框只做补充，不能代替图上的标注。
- 数据点很多（多条系列 × 十个以上时点）时，堆积面积只标每条系列首末两点、合计和关键点，删掉的中间值在交付说明里列出（rules.md 一.1）。
- 大纲没给数值的示意曲线、只表达趋势的小图：不画刻度，只标端点或关键点，并在交付说明里注明"示意"（rules.md 一.2）。

| 页型（大纲"建议呈现"） | 做法 |
|---|---|
| 封面 | `01_cover`：标签 → 标题（48 px，最多两行，按语义断行）→ 副标题 → 机构 / 日期 |
| 目录 | `02_toc`：每章一行，"01" 砖红大号编号 + 章节名（冒号前）+ 说明（冒号后）+ 虚线分隔；行高 = 可用高度 ÷ 章节数 |
| 柱 + 折线趋势 | 左：柱（海军蓝渐变）+ 折线（砖红，浮在柱上方）+ 阶段底色带 + 标注气泡 + 同比胶囊行，整块放在浅蓝面板里，图宽占正文 55–60%；右：粉面板 + 栏头条，顶部 1 个英雄数字，下面阶段诊断 / 发现行 + 证据框；底部贯穿箭头带或框架条 |
| 漏斗 | 中：立体切面漏斗（每层左右两半深浅不同，最弱环节砖红）；左翼：阶段定义 + 图标圆 + 圆点虚线连到层；右翼：转化率圆 + 环节名 + 流失标签 + 弧形箭头；远端：关键指标证据框 + 剩余人数小图 |
| 中心辐射 | 中：核心圆 + 同心虚线环 + 4–6 个带编号徽章的节点；两翼：无卡片条目（编号 + 名称 + 指标 + 分隔线 + 标签 + 说明），圆点虚线连到节点；两翼下各一个证据模块 |
| 百分比圆环 ×N | 不要 N 个等大圆环平铺。最能支撑结论的一个做成主视觉大环（r 110–130，砖红弧，环内英雄数字），其余缩成卫星环（r 50–60）挂在主环周围或一侧，用圆点虚线 / 编号串到主环；有包含关系的指标（某个整体内部几部分各占的比例）合成一个分段环。各环放在所属面板里；底部框架条或箭头带收束 |
| 左右双图（堆积柱 + 堆积面积） | 两图各占一块浅底面板 + 深色栏头条，栏宽按类目数分配；主视觉是更能支撑标题的那张图（占宽 55% 以上），另一张缩小；系列直接标注在末端；大纲"注"作为图下一行 13.33 说明；份额变化做成胶囊行，胶囊行左端直接写行名 |
| 数据看板 | 顶部 4 个 KPI（大数字 + 单位 + 同比胶囊 + 图标圆），下方 3 个小图按信息量分栏；区块标签用大纲里的分组名 |
| 左右对比 | 左蓝右红两翼条目逐行对齐，中间一列对照指标（镜像条形 + 数值），行间浅灰虚线、栏间细竖线，不铺底色 |
| 表格 + 发现 | 原生形状表格：表头海军蓝白字，首列浅蓝底；焦点列砖红细框；右侧发现栏（编号 + 一句话）贴右边界 |
| 雷达 | 多边形网格（同心虚线，边数 = 维度数）+ 每个对象一条半透明多边形；右侧发现栏；每个顶点标维度名 |
| 2×2 矩阵 | 主图四象限（被强调的一格用浅色底带）+ 轴名放两端"低 / 高"；右侧核心数字 + 判断 |
| 蝴蝶图 | 中轴放因素名，左右对称条形（左蓝右红），差值最大的两项砖红强调；条形末端标值 |
| 人物画像 | 左：人物图标圆 + 名称 + 标签语 + 标签胶囊；中：基础属性与核心诉求；右：指数横条（基准值为参考线）；底部引号块放用户原话 |
| 气泡图 | 两轴 + 按系列着色的气泡（面积 ∝ 第三个变量）+ 关键区间的底色带；气泡就近标注名称 |
| 微笑曲线 | 平滑曲线 + 各环节节点（高附加值两端砖红）+ 每节点下方说明；左右两端区块标签 |
| 金字塔 | 自上而下按层数做立体切面（左右两半深浅不同），右侧编号说明行逐层对齐，左侧一条表示层级方向的竖向箭头（两端写大纲给出的方向词） |
| 时间轴 | 一条主轴 + 年份节点，重点节点砖红并放大；说明上下交错，避免拥挤 |
| 多列卡片 | N 列等宽，每列：名称 → 分类胶囊 → 大数字 → 三条要点；列间细竖线，不画卡片阴影 |
| 战略屋 | 屋顶（砖红/海军蓝渐变三角或梯形，写目标）→ 4 根支柱（标题 + 要点）→ 地基（通栏）；支柱与地基两端贴齐边界 |

## 三B、定性框架页（大纲是概念、流程、清单而不是数据时）

先读大纲里每个内容块的**关系**（递进、循环、包含、对比、并列、层级、时间），再按下表选构造；一页通常由 2–4 个构造拼成，最大的那个是主视觉。

| 大纲里的关系 | 构造做法 |
|---|---|
| 顶层理念 + 两大支柱 + 共同基座 | 屋顶：`triangle` 浅蓝底 + 海军蓝描边，顶部写理念、底边一行放三个要素（中间一个做成深色胶囊）；两根深色竖柱（宽 44–48，渐变）里逐字竖排支柱名；柱间放上下两块面板（上浅蓝、下浅粉）；底部一条比屋身略宽的深色基座条 |
| N 个环节首尾相连的闭环（4–8 个） | 两行网格：每格"上方 14.67 标签 + 深色矩形里写环节名 + 下方标签"，上行 `rightArrow` →、右端 `downArrow` ↓、下行 `leftArrow` ←、左端 `upArrow` ↑，绕成环；或圆盘：浅蓝大圆按阶段分扇区（白色分隔线）+ 中心深色核心圆 + 环上 r 26 节点圆 + 扇区间弧形箭头 |
| 阶段依次推进（3–5 段） | 顶部一条连续色带：首段 `homePlate`、其余 `chevron`，彼此重叠一个尖角，关键阶段砖红；下方内容按阶段对位（第三C节第 5 条），阶段边界画浅色虚竖线 |
| 用户旅程 / 热度有起有落 | 一条平滑曲线（3 px 海军蓝，Catmull-Rom 转三次贝塞尔）穿过节点圆，峰谷落差至少占曲线面板高度的 60%（起伏要夸张，不要接近直线）；关键节点砖红放大；节点标签做成色块小标签或胶囊（峰上、谷下），说明 12 px 放在标签下面；节点落在所属阶段的横向区间内（第三C节第 6 条） |
| 多步走且首尾相接 | U 形轨道：上排 `homePlate`+`chevron` 向右，右侧一段 36 px 粗弧线转弯，下排同样的形状整组水平翻转向左（写法见第四节）；步骤编号写在白色描边小圆里；每步下方一张浅蓝卡片（按"标签 + 要点"写，第三D节）；U 形内侧放"落脚点"关键词 |
| 维度并列（左边是维度名，右边是内容） | 深色竖向标签条（宽 36–48，逐字竖排白字）贴在面板左侧；同页多个维度用蓝 / 砖红区分 |
| 5 个左右的要素清单，每项有说明 | 竖向时间线：一条砖红竖线串起 r 24 的砖红圆（圆内写要素名），右侧砖红 14.67 标题 + 12 px 说明，放在浅粉面板 + 砖红栏头里 |
| 从 A 转向 B 的对比 | 左右两块虚线面板（按 rules 二.6：左/现状海军蓝、右/新方向砖红），各有深色栏头；中间三个小 `chevron`（红→灰→蓝）表示转变，转变的说明写在箭头上；结论句做成整页宽的深色横条放在最上面。**两侧结构相同时要把差异画出来**：两侧用同一套骨架和位置，只把发生变化的部分（新增、断开、方向改变的环节）用砖红、加粗或标注小标签突出 |
| 4–5 个结果 / 收益 | 2×2 浅蓝图标卡（图标圆 + 18.67 标题 + 13.33 说明）+ 一张通宽深色卡放最重要的一项 |
| 时间演进中两种状态交替 | 两条平行横轴（海军蓝 / 砖红），年份标在上方，各状态做成色块标签按年份跨度落在对应轴上 |
| 很多并列的活动 / 标签 | 胶囊云：重点项实心砖红白字，其余在描边圆角、浅粉底、虚线框三种样式间交替，按两三行排满面板 |
| 一个总包分成几类 | 深色大圆写总包名，用折线括号分出几个砖红标签，标签右侧逐条说明 |
| 带有子项的核心概念 | 深色核心圆 + 外圈虚线环 + 环上白底小圆写子项 |
| 阶段 × 维度（若干阶段，每个阶段在多个维度上各有内容） | **不要画成表格**。顶部：每个阶段一个大圆节点（r 44–56，粗描边，浅→深渐变，最终阶段砖红）用细横线串起，圆旁带指向下一阶段的三角；圆下方各一个与列同宽的描边标题框（写该阶段的指标）。左侧维度名用纯文字列（M 16–18.67，不加底色块）。单元格是"浅色标签头条（阶段色）+ 两三条要点"的小卡，同一维度一行对齐、不画格线。**每格只放所属列的内容**：某列在某维度上没有内容时留空或放浅色占位块，不把相邻列的内容横向拉过去补位。跨多个阶段的项目做成一条通栏深色条，下方用旋转 90° 的大括号归到它服务的阶段 |
| 三项等权并列（三个步骤、三个机制） | 每一项都做成"主角组"：一个 96–120 px 的超大字（项目的关键字，海军蓝或砖红渐变，部分被压在圆后面）+ 一个深色大圆（r 70–90，写项目名，英雄关键词）+ 2–3 个白底描边卫星圆（r 34–40）压在大圆边上写子项；三组并排、大圆颜色蓝红蓝交替，本身就是主视觉；上方用一条深色栏头统领，下方再放模块卡。卫星圆的圆心落在大圆边线上，彼此间距 ≥ 8 px；大圆里的英雄关键词与卫星圆外缘至少留 12 px |
| 两组维度叠加，分别得出两个结果 | 中间一个大圆（r 110–130）被一条斜线分成两半，两半各写一个结果名（白字，英雄关键词）；左侧清单（第一组维度）用折线箭头指向一半，右侧清单（第二组维度）用折线箭头从另一半引出；清单项做成浅色胶囊标签 + 括注小字 |
| A ∩ B = C（两类对象的交集） | 两个大圆（r 100–120）左右相交，左海军蓝、右砖红，各自圆内写集合名（英雄关键词）；交集透镜用 `shape_boolean_svg.py intersect` 做成白色或浅色，透镜里写交集名 C（不是只写"∩"）；两侧各挂 3–4 个浅色小圆写各自的组成项，底部一排深色标签写数据来源，用细箭头指向对应的圆 |
| 由内到外层层包含（核心 ⊂ … ⊂ 最外层） | 底部相切的嵌套圆（或椭圆）：所有圆底边落在同一条线上，半径由内向外递增约 1.4 倍，最内圈砖红、向外逐层变浅；每层的名称写在该层露出的上沿空白里，子项做成小胶囊散布在本层环带内；整组直径至少占所在栏宽的 80% |
| 问题 → 解法 | 左右两列：左列深色栏头"问题"+ 圆点清单，右列砖红栏头"解法"+ 圆点清单，中间一个 `rightArrow`；两列等高，内容少的一列用说明或数据框补满 |
| 分层图 / 漏斗与旁边的策略一一对应 | 每层用弧形箭头（`curvedRightArrow` 或带 marker 的 Q 曲线）指向对应策略。大纲写"一一对应"但数量对不上时：先按**语义**归组（看每一层和每条策略说的是不是同一类对象），语义判断不了再按顺序；多对一时用大括号把几层归到同一策略，并在交付说明里写明这是推断 |
| 起点集合 → 逐层筛选 | 来源或总集合（椭圆、池子、圆柱）与下面的漏斗 / 分层图之间加向下的箭头或收口线，不让两者断开 |

**一页同时有两组箭形色带时**：阶段色带用深色实底（海军蓝 / 砖红）、高 36–40；链条或流程色带用浅色底 + 深色字或描边、高 28–32，两者一眼能分开。

**高密度页（5 个以上内容块）的取舍顺序**：① 先给主视觉定好位置和面积：5 个内容块时不小于正文区 40%，6–8 个时不小于 35%；② 其余块压缩成胶囊行、圆点清单或小卡，按栏头 + 列表排；③ 仍放不下时把说明文字缩到 12 px；④ 任何情况下都不删大纲内容、不省区块标题。多栏顶部先对齐，再用说明、数据框或卡片补满底部空带。

**卡片与格子要"满"**：
- 每张卡片至少一个图形元素（图标圆、迷你示意图、胶囊行、编号块或色块标签），不要让卡片只装文字；大号淡色编号 + 段落的卡片也要再配一个小图形，避免这一侧的图形密度明显低于主视觉一侧。
- 卡片里只有一两个关键词时，放大字号、加图标或圆形节点，不在大卡片里留大片空白。
- 一行格子按内容最多的那格定高时，内容少的格子把内容放大、改成胶囊或标签排开，或者把这一行的行高收紧；每个格子底部的空白不超过格子高度的三分之一（rules.md 二.10）。
- 主视觉里的核心圆盘、环形图直径不小于 260 px。

定性页的字号可以更密：说明文字 12–13.33 px；标签、步骤名 14.67–18.67 px。图标统一用一个图标库、放在深色圆里白色显示。

## 三C、模块之间的连接与对位（rules.md 二.11）

关系要画出来：只靠并排、相邻或对齐，读者看不出谁对应谁。

1. **次级模块接到主视觉上**：主视觉旁边或下方的清单、胶囊云、证据框、指标框、小图表，如果对应主视觉里的某个节点或某一项，就用细箭头、圆点虚线引线、同色编号，或在模块顶上加一个写着主视觉里那个节点原词的小标签（只用原词，不另加"支撑""对应"之类的词）连过去。
2. **上下半区连起来**：上半部是主图、下半部有多个模块时，用箭头、括号或引导线把下半部各模块接到上半部（或把它们彼此串起来），不要让下半部像几张互不相干的表。
3. **大区之间画出承接**：一页有两三个大区，且大纲写了"承接 / 推进 / 由…到… / 转向"之类的关系时，大区之间至少放一个粗箭头或箭头带；描述这层关系的那句话写在箭头上，不单独占一行。
4. **起点容器接箭头**：用椭圆、池子、圆柱表示来源或总集合时，与它下游的图形之间一定有箭头或收口线。
5. **阶段带与下方内容对位**：页面上有 N 段 chevron 阶段带时，下方每个内容区都落在对应阶段的列宽里，或用编号指回某个阶段；对不齐时，把阶段带缩到只含有内容的那几段，或把多出来的阶段合并成一个括号区间。
6. **曲线 / 时间轴与阶段带对齐**：同一页同时有阶段带和曲线或时间轴时，曲线节点落在所属阶段的横向区间内，阶段分界处画竖向浅色虚线贯穿曲线区。
7. **对齐即暗示对应**：上下同列堆叠、左右同行排列的模块，读者会默认它们一一对应。确有对应关系时才这样对齐，并用编号或连线确认；没有对应关系时把它们错开、放进不同面板，或用分隔线隔开。

## 三D、文字装进容器

1. **节点说明用"标签 + 小字"**：主视觉节点旁的小标题做成色块标签或胶囊，说明用 12–13.33 px 放在标签下面，不放裸文本。
2. **步骤 / 卡片说明按"标签 + 要点"写**：每一步或每张卡的说明，开头用色块小标签写关键词，后面的条目用圆点或编号；不要把整段文字直接铺在浅底面板里。面板高度按内容收紧，或用重点数字、胶囊填满。
3. **栏头下的短条目进容器**：阶段带或栏头下面的短条目，优先放进胶囊或浅底小格；说明段落超过两行时，给它浅底面板或左侧 4 px 色条。

## 四、技术要点（ppt-master 约束）

**结构与分组**
- 根节点带四个 `data-pptx-master/-layout` 属性，与所用原型一致；页框原子与 slot 原样保留在最前面，正文 `<g>` 在后。
- 每个根层内容 `<g id>` 必须有 `data-pptx-bounds`，根层组之间重叠不超过 1 px（slot 组与 `data-pptx-role="decoration"` 除外）。
- **主图与贴着它的标注放进同一个组**：漏斗和它右侧的层标签、转弯弧和压在它上面的文字、核心圆和卫星圆，都放在同一个根层组里，不要拆成会互相重叠的两个组。
- 大构造拆组：U 形轨道拆成"上排色带组 / 转弯弧组（含 U 内文字）/ 下排色带组"三个互不重叠的组，每步卡片按"上排卡片组 / 下排卡片组"放在轨道之间；其他大构造（色带、长曲线）同理按不重叠的横条拆。
- 横跨多个组的底色面板写成根层 `<rect id="…" data-pptx-role="decoration">`（不包 `<g>`），它不参与重叠检查。

**箭头与变换**
- `marker-start` / `marker-end` 只能写在 `<line>` / `<path>` 上，写在 `<g>` 上会报错。
- **粗线不挂 marker**：线宽超过 4 px 的线或弧带（如 20–36 px 的转弯弧）挂 `marker-end` 时，导出后箭头会按线宽放大；这类粗线的箭头改用单独的三角形 `<path>`（按线端切线方向计算三个顶点）或 `triangle` 预设，颜色与线一致。
- **水平镜像**：把要翻转的 preset 片段原样放进一个外层 `<g transform="matrix(-1 0 0 1 W 0)">`（W = 镜像轴 x 的 2 倍），transform 写在这个外层组上，不改 preset 片段本身；外层组放在一个带 `data-pptx-bounds` 的根层组里，bounds 写翻转后的实际位置。
- `filter`（阴影）只能挂在单个 `circle` / `rect` / `path` / `text` 上，挂在 `<g>` 上导出会失败。

**文字**
- 多行文字的续行 `<tspan>` 必须重复父级 `x`（悬挂缩进另起一个 `<text>`）。
- 竖排文字：一个 `<text>`，每个字一个 `<tspan x="同一 x" dy="字高×1.3">`。
- 页面标题不超过 20 个汉字（标题框约 880 px）。大纲标题超长时不改字，把这一页的标题字号逐级降到 34.67 / 32 px，按校准表确认单行放得下；32 px 仍放不下时保持单行原字号并在交付说明里提示用户缩短。
- 文本统一 `lang="zh-CN"`（写在根 `<svg>`）。
- 不用 `style` / `class` / `mask`。

**图表与导出**
- 图表绘图区写标记：`<!-- chart-plot-area: object=<key> | x_min,y_min,x_max,y_max -->` 放在 `<g id="<key>-chartArea">` 里；柱高、折线点用 `svg_position_calculator.py` 核对。
- ppt-master 不认识 OPPOSans 的中文槽位，导出后由 `fix_cjk_fonts.py` 统一改回同字重的 OPPOSans（`finish` 自动执行）。

**无论点条的页（`04a`）**：大纲没有"结论 / 发现"时不放论点条，也不自造一句 so-what 顶替；正文从 y 96–100 直接开始，第一行就是阶段色带或各区的深色栏头，英雄关键词放在主视觉里。只有大纲给出的结论句超长（rules.md 一.5）时，才把那句话做成正文最上方的通宽深色陈述条。
