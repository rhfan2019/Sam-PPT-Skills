# 视觉自检清单

`qa.md` 的自动检查清零之后，按这张清单看渲染图。先看 `contact.png` 的整体节奏，再逐页放大 `render/slide-NN.png`。

## 每一页

- [ ] **边界**：所有内容都在标题分割线的左右端点之间（0.37″–12.96″），没有任何元素跨出去；论点条、区块标签、框架条贴齐这两条边。
- [ ] **同行中线**：同一行的标题、箭头、标签框、说明文字上下居中对齐，没有"文字比标签偏上"。
- [ ] **同列边缘**：上下相邻的标签列、指标框左右边缘落在同一条线上。
- [ ] **遮挡**：标注气泡、数据标签、折线标签、图例互不遮挡；气泡尖角落在它所指的数据点上。
- [ ] **溢出与断行**：没有文字被截断；数字和单位不分行（"26" 和 "万"不在两行）；中文标点不在行首；单个字不孤零零掉到下一行。
- [ ] **信息不重复**：同一个数字或结论在一页上只出现一次（图上标注和卡片不重复）。
- [ ] **口径统一**：同一组指标位要么都是数字，要么都是图标 / 文字胶囊，不混放。
- [ ] **每行都"满"**：没有一行只有半句话、右侧大片留白；空处补进度条、标签或推算的证据。
- [ ] **对比度**：深底上没有浅字、浅底上没有白字；图标颜色与所在底色对比清楚，同一页图标同色系。
- [ ] **重点**：`**重点**` 每页不超过 3 处。

## 全套

- [ ] 页头页脚（标题、手势图标、章节标签、分割线、页脚线、免责声明、署名）在每页位置完全一致。
- [ ] 同一版式没有连续出现超过两次；图表页和图示页交替。
- [ ] 所有图表的轴标签、数据标签字体字号一致。
- [ ] 推算数字已整理成清单，准备交给用户核实。
