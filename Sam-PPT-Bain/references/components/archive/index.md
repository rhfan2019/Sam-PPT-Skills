# 备用库（A01–A11）

**不必每次读。** 核心库 `../kit.md`（K01–K19）里没有对得上本页内容的写法时，再按下表查。效果见同目录 `overview.png`（PowerPoint 渲染的原件，文字是占位词）。

这些写法由脚本从参考材料自动转换为 SVG，**没有经过 ppt-master 导出验证**：用之前先 `put` + `preview` 看效果；预设形状写成 `<!--P-->` 标记，`<!-- 原件渐变 … -->` 注释表示原件是渐变、标记里只给了中间色。坐标是原件位置，复制后整组平移或按比例改。某个备用构件被反复用到、效果好，就整理进核心库。

| 编号 | 用于 | 写法要点 |
|---|---|---|
| A01 | 通栏摘要条：一页底部或顶部，把 3 组“类别 + 要点”压成一条 | 浅蓝虚线框里排 3 个深色标签块（蓝红蓝），每块右侧 3 行小号要点 |
| A02 | 一排并列的短标签（关键词、维度名） | 海军蓝虚线描边的圆角胶囊，等宽等距 |
| A03 | 一行标签 + 一条横向内容条（编号或类别在左，内容在右） | 左端砖红实块写两行短字，右接浅粉条 + 砖红细描边 |
| A04 | 不加底色的小节：标题 + 编号清单 | 标题下一条砖红粗下划线，清单用“1、2、3、”编号 |
| A05 | 带指标的要点卡：卡头写“名称：数字”，卡身放要点 | 浅蓝卡、海军蓝细框，卡头与卡身用细线分开 |
| A06 | 两部分构成的单个数值（上下两段的堆叠细柱） | 蓝红两段细柱，数值标在柱顶和柱底 |
| A07 | 两项相乘 / 交叉组合（A × B） | 两侧粗体关键词，中间 `mathMultiply` 运算符 |
| A08 | 标出一段跨度（时间区间、范围） | 双向箭头细线，说明文字断开线条居中 |
| A09 | 一句需要强调的判断或引语 | 海军蓝粗框（约 3 px）白底，大字两行居中 |
| A10 | 主视觉参考：核心 + 多层圈层（同心圆 + 节点） | 浅蓝大圆环套小圆环，环上海军蓝节点，中心砖红三圆；只学层次，构图按内容重排 |
| A11 | 主视觉参考：椭圆轨道上的循环 / 平台 | 浅蓝渐变椭圆环 + 轨道上海军蓝节点 + 弧形箭头，中心写主题；只学层次，构图按内容重排 |
