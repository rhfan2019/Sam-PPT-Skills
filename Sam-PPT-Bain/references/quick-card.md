## 版面纪律（rules 二、§三B、§三C、§三D、§三E）

- 一个主角：主视觉有体积感（渐变 / 白色外晕 / 阴影 / 分层），是全页最大最重的图形，配角平面、用连线和编号接到它上；数据图只突出一个点并直接批注（Style spec §III–V）。
- 主视觉占正文 45–60%；5 块内容 ≥ 40%，6–8 块 ≥ 35%；不足时按 §三B"腾空间"六步走，不删内容。
- 构图纪律（rules 二.12）：一条阅读主线，区块 ≤ 4（5 个以上内容组时合并成 ≤ 4 个大区，组标题留在大区里，不删内容）、大号连接符串起；同级并列项同一单元，单元写法 ≤ 3 种；大数字 ≤ 3、英雄数字 ≤ 1；栏距 12–16、内边距 ≥ 12、同行等高；图表只在条尾柱顶标数，类目标签 ≤ 2 行。
- 构件分区：每页至少用 `components/kit.md` 的 2 种构件（K01–K19，按文末选择表挑），写法照搬、只改坐标尺寸文字；每处深色都标出一个真实大区或对象；红色 ≤ 20%（rules 二.8）。
- 满而不挤：底部无整条空带，模块内部无空洞；主视觉四周的留白是呼吸感，不补规则条和胶囊（rules 二.10）。
- 动笔前看 `approved/samples.md` 里对应页型的样张，学质感和层次，不照抄构图。
- 关系要画出来（箭头 / 引线 / 括号 / 同色编号 / 原词小标签）；没关系的不对齐。推断的连接写进交付说明（§三C 8–9）。
- 卡片至少一个图形元素；格子底部空白 ≤ 1/3；不用淡色大图标、大号淡编号、水印补位。
- 节点说明用"标签 + 小字"；短条目进胶囊或浅底小格；不留裸段落（§三D）。
- 精炼页（< 200 字或 3–6 短条）：放大字号不放大形状，组团 60–75%，写进交付说明（§三E）。

## 技术（§四、digest）

- 根层 `<g id>` 带 bounds（可写 `auto` 由 put 实测），组间重叠 ≤ 1 px；横跨面板用根层 `<rect data-pptx-role="decoration">`。
- marker 只挂 `<line>/<path>`，**一条带箭头的 path 只能有一个 M**；线色 = marker 色；> 4 px 粗线不挂 marker。
- filter 只挂单个图元；不用 style / class / mask；tspan 不写 font-family；续行 tspan 重复 x。
- 预设一律 `<!--P …-->`，翻转 / 旋转写外层 g；漏斗 trapezoid 旋转 180。
- 构件标记 `<!--C pill|head|num …-->`、`<!--T …-->` 只用于小构件，主视觉必须手写（SKILL.md 第 5 步）。
- `put` 打印的 `LINT … [WARN]`（大块 > 4、数字焦点过多、小字过多、线穿字、卡片空底、占位块、装饰补位）交付前逐条处理，不改的在交付说明里写明理由。
