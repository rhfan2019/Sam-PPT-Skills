# 用户的硬规则与经验

> 来自 2026-10-21 的多轮评审（咨询卡片版 → 精修版 → 咨询版 → ppt-master 试点）。与引擎无关，换任何实现都成立。

## 一、内容纪律（最高优先级）

1. **不替大纲加词**。标题、论点条、条目只用大纲原句或原句的拆分；不添加大纲没有的事实、修饰语或口号。确需缩短时只删不改，并在交付时列出。栏头加 01/02 这类编号不算加词；用大纲里出现过的词做栏头、区块标签或标题条也不算加词（大纲里写了"三个步骤""第一阶段"这类词，就可以把它们做成栏头）。大纲没出现过的概括词（自拟的分类名、口号、小结语）不能当栏头。大纲括号里的关系说明（"依次推进""一一对应"）可以改用图形表达而不写出来。分类标签、类别名逐字照抄大纲：不自己补括注，不合并、不改动类别。
2. **推算值可以用、必须列出——但只在交付说明里列**。同比、份额、差值、转化率、倍数、年复合增速等由大纲原始数据算出的数字，可以用来提高信息密度，交付时逐条写出算式请用户核实。大纲没给数值、只表达趋势的示意曲线或小图，也在交付说明里注明"示意"。**页面上只放结论数字**：不写算式（"A × B""A − B"）、不写"（推算）"、不写"据第 N 页数据"之类的工作底稿字样。
3. **同一信息只出现一次**。图上已标的数字不再进证据框；证据框只放"本页正文没出现过"的推算值或跨页引用。这条只约束 Skill 自己加的推算值和证据框；**大纲本身在不同位置重复的内容，每个位置都照写**（可用相同构件重复展示），不要合并成"同上"。
4. 大纲标了"示例数据"的，页脚免责声明写"示例数据，不作为真实统计引用"。
5. 论点条写本页 so-what，取自大纲的"结论 / 发现"原句，与标题互补、不重复标题。**超宽时先降字号档位、后断行**：单行按 26.67 → 22.67 → 21.33 px 逐档试，按校准表实测宽度不超过 1110 px 就停（字数参考：≤ 40 字 26.67，41–48 字 22.67，49–54 字 21.33，含标点）；21.33 px 单行仍放不下时，在同一条论点条里断成两行 21.33 px（在标点或语义停顿处断，第一行不短于第二行，基线 120.4 / 146.4）；两行仍放不下才不放论点条（用 `04a`），把这句话做成正文最上方的通宽深色横条。
6. **不加整页"注："**。大纲里的"注"写成所属模块正下方的一行说明（13.33 px，不加"注："前缀也可以）；除此之外页面不写图例式说明句（"柱：…　线：…　胶囊：…"），能直接标注的就直接标注。
7. **区块标题一个都不能省**。大纲里每个内容组的标题（区块名）都要上页，做成栏头、色块标签或区块标签；版面紧时压缩组内条目的写法，不删标题。
8. **内容放在它所属的位置**。按阶段、列或维度组织的内容，每一项只放在所属的那一格；某格在大纲里没有内容就留空或放浅色占位块，不把相邻格的内容挪过来补位。

## 二、版面硬规则

1. **左右边界 = 标题线两端：x 35.93 与 1244.07**。任何内容元素不得越界；全宽元素（论点条、底部框架条、通栏分隔线）两端贴齐。
2. **同一行共用一条中线**：图标圆、标题、箭头、标签框、说明的垂直中心一致。
3. **同一列边缘对齐**：同一栏、同一组里上下相邻的模块，左右边缘落在同一条线上（不同组之间的对齐见二.11）。
4. 正文区下界 y 672（页脚线 687.01 上方留白）。
5. 深色底（海军蓝、砖红实底）上的白字不小于 12 px，说明性小字不放在深色底上；浅蓝 / 浅粉底不放白字。
6. 颜色表达"属于哪一侧"：左/用户/现状 = 蓝系，右/策略/判断 = 红系；红色面积 ≤ 全页约 20%。砖红面板里也只给栏头、节点和重点项用实色砖红，长文和普通胶囊用中性色或描边。
7. **每页一个主视觉**。一个概念图形或主图表占正文区 45–60%，是全页视觉重心，其余模块围着它排；它可以跨过区块边界。不要用 N 个同尺寸模块等分并排作为整页结构——同类小图可以并排，但必须有一个被放大的主角，或有一个把它们串起来的大图形。内容很少的"精炼页"按 page-patterns 三E 处理，不为凑面积拉伸几何。
8. **分区靠构件，深色要有含义**（2026-10-23 第二次修订：先前"深色栏头条每页最多 2 条、1–3 处深色实块"矫枉过正，参考材料里多数正文页用多个深色页签和侧标签条分区）。大区和并列对象用 `references/components/kit.md` 的构件划分和命名：页签 + 浅底面板、竖排侧标签条、人字箭头色带、立体标签。深色只出现在这些构件和主视觉上，**每一处深色都标出一个真实的大区或对象**；不给每个小模块顶一条深色栏头，不放没有含义的深色装饰块。模块内部再细分时用 1 px 浅色细线框（#8EA9CF 或 #E3A79C，虚线 `4,3`）或留白，不用深色粗框。
9. **字号三档，拉开对比**。**每页至少一个焦点，同级焦点不超过两个**：焦点是英雄数字（≥ 40 px，常用 48–64 px B）或英雄关键词（核心圆、核心色块或大字标签里的 2–6 字概念词，24–32 px）。本页大纲没有数字，或页面上的数字都是并列 / 重复关系、挑不出主角时，用英雄关键词。第三个以上的数字降到证据档（28–32 px）。例外：结构完全相同、等权并列的一组（三项等权的主角组、一排统一字号的并列数字）整体算一个焦点。标签 / 条目标题 17.33–21.33 px M 并着色；说明 13.33–14.67 px R。小字的用量上限见 page-patterns 一；8 px 只用于页脚。每页正文字号不超过 6 种（怎么数见 page-patterns 一）。
10. **满而不挤**（2026-10-23 依样张修订，原为"版面填满，不允许局部出现 > 40 px 空带"）。正文内容的下缘到 y 664–672，底部不留整条横向空带（> 40 px）；卡片和格子底部的空白不超过它自身高度的三分之一。**主视觉四周、大区之间的成片留白是有意的呼吸感，不算空带**（见样张 07、08）：不要为了填满在底部加规则条、说明条，也不要把每个空隙都塞进胶囊或小卡。禁止的是"模块内部的空洞"和"底部整条空带"，不是留白。格子偏空时先补本块的真实内容、再调格子尺寸（做法见 page-patterns 三B"卡片与格子要'满'"）；**不用淡色大图标、大号淡色编号、水印字之类的装饰补位**。例外：精炼页（page-patterns 三E）的内容组团可以只占正文区 60–75%，组团外围的留白不算空带；"无 > 40 px 空带"在精炼页只约束模块内部和模块之间。
11. **关系要画出来**。模块之间的对应、承接、包含、推进关系，必须用箭头、连线、括号、编号或写着对应节点原词的小标签画出来，只靠并排、相邻或对齐不算；反过来，没有对应关系的模块不要上下同列或左右同行地对齐排列，以免暗示一一对应。大纲没写明关系时该不该连、数量对不上时怎么对应，按 page-patterns 三C 第 8–9 条判断，按推断画的对应关系在交付说明里列出。做法见 page-patterns 三C。

12. **构图纪律**（2026-10-23，依参考材料逐页对比补充）。
    - **一条阅读主线**：整页只有一个阅读方向（左 → 右或上 → 下），正文区块不超过 4 个；区块之间用大号连接符画出顺序或关系（`chevron` / `rightArrow` 至少 28×40、`mathPlus`、带箭头的引线），与其他区块都没有连接的区块最多 1 个。
    - **同级内容同一单元**：同一层级的并列项用完全相同的单元重复排列（同尺寸、同内部结构、同字号同颜色），不要每项换一种写法；一页里的单元写法不超过 3 种（构件库的每种构件、每种图表各算一种）。
    - **焦点数**：每个区块最多 1 个大数字（≥ 28 px），整页大数字不超过 3 个，其中英雄数字（≥ 40 px）最多 1 个；其余数字用正文字号、着色或加粗表达。
    - **留白与栏距**：区块之间的间距统一取 12–16 px；单元内边距不小于 12 px，文字不贴边框和分隔线；同一行的单元等高，单元内文字统一居中或统一左对齐，不混用；内容少的单元缩短高度，不留空洞。
    - **图表标注从简**：数值只标在条尾或柱顶；类目标签最多两行，放不下时改用横向条形或加大类目间距，不在柱下堆三行说明；说明性的句子移到图旁的一个说明块里。

## 三、"咨询感"从哪里来

| 做法 | 说明 |
|---|---|
| 结论先行 | 页面标题（结论句）→ 论点条（so-what，按版式可选）；需要说明左右各讲什么时再加浅色区块标签 |
| 一个主角 + 配角 | 一个有体积感、占正文区约一半的主视觉（按大纲关系选构造，见 page-patterns 三、三B 和 Style spec §III）是全页最大最重的图形；其余内容作为 2–4 组配角排在它周围。区块标签、证据框、底部框架条都是可选构件，内容里确有对应关系时才用（2026-10-23 依样张修订，原为固定的"五区构图"） |
| 去卡片化 | 配角浮在版面上，用对齐、圆点虚线、弧形箭头、右箭头、编号连到主视觉；不用等大卡片墙，卡片只留给标签框和证据框 |
| 构件分区 | 每页至少用构件库（`references/components/kit.md`）的 2 种构件：页签面板 / 侧标签条划大区，指标块和光晕底板托数字，人字箭头串阶段，立体标签写类别；构件写法直接复制，构图随内容变化（rules 二.8） |
| 字号对比 | 每页 1–2 个特大数字（约 60 px）与 13–14 px 说明形成强对比，缩略图上一眼看出层级 |
| 信息颗粒细 | 一条 = 图标圆 + 粗体标题 + 说明 + 标签框；证据框里允许 10.67 px 的单位 |
| 立体与质感 | 主视觉用同色相渐变（海军蓝 #16365F→#2E5A94，砖红 #8E2B1D→#C0503E）、白色外晕、分层深浅（漏斗/金字塔每层左右两半深浅不同）；浮起的圆加柔和阴影。质感集中在主视觉上，配角保持平面 |
| 跨界与交叠 | 徽章压在节点边、图标圆压在线端、实物图压在核心圆下 —— 每页至少一处，打破格子感 |
| 图表带批注 | 每张图只用砖红标出要读者看的那一个点，其余系列退到浅蓝灰；阶段底色带、参考线、指向具体数据点的标注气泡或带箭头的短句批注、与类目对齐的同比/份额胶囊行 |
| 编号串联 | 图中节点与两翼条目用相同编号（01–06），读者不用顺着连线找 |

## 四、用户确认过的具体做法（2026-10-21）

- 多栏页面**栏宽按内容分配**（图表按类目数、证据栏固定宽），不要机械等分；栏间 ~20–30 px 留白，每栏用浅底面板或栏头条界定（见二.8）；区块标签 / 栏头条与栏同宽。
- 对比页**让"行"可见**：左右两翼条目与中间指标逐行对齐，栏间细竖线、行间浅灰虚线；**不要给单元格铺底色**（会变成表格感）。
- 坐标轴能省就省：每根柱子都标了值时去掉刻度和网格线。
- 柱线组合时折线浮在柱子上方，避免标签互相遮挡。
- 直接标注代替图例：系列名写在最后一个数据点右侧。
- 竖排文字里不要放箭头（会跟着转向），轴的方向用两端的"低 / 高"小字表达。
- 内容里确有推进或"A ⇄ B"对照关系时，底部可用箭头带或框架条收束全页；没有就不加，不为收束而收束。

## 五、流程偏好

- 方向没确认前，先做 2–3 张代表性样张给用户看，不要大面积铺开。
- **只有用户说"可以了"的页面才算样张基线**。不要自己宣布通过，不要把未确认的页面当标准。
- 用中文沟通；每轮把新经验沉淀进本文件或 `page-patterns.md`，并提交推送。
- 以专家身份给出建议和判断，而不是让用户试错。
- **返工时先换构造，不打补丁**：用户说某页"空""简陋""不够咨询感"时，先回 page-patterns 三B 的"关系 → 构造"表，按大纲内容之间的关系重选主视觉，再按"一个主角 + 配角"逐项核对（本文件三）；内容本来就少的，按 page-patterns 三E 的精炼页处理。不要在原版式上加卡片、图标格或拉大形状来修补——那样只会更像模板。
- **不依赖图片**：用户常用的 PPT 没有图片。主视觉、质感全部用原生形状和渐变构建，不要因为没有素材图而降低主视觉的分量。

## 六、每页自检清单（写完每页、看渲染图时都过一遍）

- [ ] 所有元素在 x 35.93–1244.07、y ≤ 672 之内；全宽元素两端贴齐
- [ ] 同行中线一致、同列边缘对齐；数字与单位不分行；无文字溢出或遮挡
- [ ] 标题是结论句；论点条与标题不重复；同一数字只出现一次
- [ ] 每个词都能在大纲里找到；推算值已记下算式（只记在交付说明里，页面上没有算式、"推算"、"据第 N 页"）
- [ ] 有一个占正文区 45–60% 的主视觉（高密度页见 page-patterns 三B 的下限）；不是 N 个等大模块平铺
- [ ] 大纲里每个区块标题都上了页；每项内容在它所属的格 / 列 / 阶段里
- [ ] 次级模块都用箭头、连线、编号或对应节点的原词小标签接到主视觉或彼此串起；阶段带、曲线与下方内容对位
- [ ] 节点和步骤说明用"标签 + 小字 / 要点"装进容器，没有成段裸文字
- [ ] 构图纪律（二.12）：一条阅读主线、区块 ≤ 4 且用大号连接符串起；同级并列项是同一种单元；大数字 ≤ 3、英雄数字 ≤ 1；栏距 12–16、内边距 ≥ 12、同行单元等高、没有空洞单元；图表下没有多行说明
- [ ] 至少用了构件库的 2 种构件，写法和比例照搬 kit.md；每一处深色都标出一个真实的大区或对象；和上一页的构件组合、位置不雷同
- [ ] 对照 `approved/sample-*.png` 问三件事：主角是谁？哪些框和栏头可以删？读者第一眼看到哪里？
- [ ] 至少一个、至多两个同级焦点（≥ 40 px 英雄数字或 24–32 px 英雄关键词）；正文字号 ≤ 6 种；10.67 / 12 px 没有超出用量上限
- [ ] 缩略图上第一眼落在主视觉上，说得出"这页的主角是什么"；主视觉有体积感（渐变、外晕、阴影或分层），配角保持平面；数据图只突出一个点并有图上批注
- [ ] 内容铺到 y 664–672，底部没有 > 40 px 的整条空带（主视觉四周的留白不算），卡片 / 格子底部空白 ≤ 1/3；每行信息"满"，没有靠淡色大图标或大编号补位（精炼页按 page-patterns 三E）
- [ ] 一页一个图标家族、同色；左蓝右红语义一致；看渲染图时逐个确认图标不加文字也读得出原意（page-patterns 二"图标语义"）
- [ ] 折线图的必标点都标了数（page-patterns 三）；编号圆、胶囊、引线端点之间的间距够（page-patterns 二"编号与间距"）
