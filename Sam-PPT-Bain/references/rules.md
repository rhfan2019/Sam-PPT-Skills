# 用户的硬规则与经验

> 来自 2026-10-21 的多轮评审（咨询卡片版 → 精修版 → 咨询版 → ppt-master 试点）。与引擎无关，换任何实现都成立。

## 一、内容纪律（最高优先级）

1. **不替大纲加词**。标题、论点条、条目只用大纲原句或原句的拆分；不添加大纲没有的事实、修饰语或口号。确需缩短时只删不改，并在交付时列出。
2. **推算值可以用、必须列出——但只在交付说明里列**。同比、份额、差值、转化率、倍数、年复合增速等由大纲原始数据算出的数字，可以用来提高信息密度，交付时逐条写出算式请用户核实。**页面上只放结论数字**：不写算式（"A × B""A − B"）、不写"（推算）"、不写"据第 N 页数据"之类的工作底稿字样。
3. **同一信息只出现一次**。图上已标的数字不再进证据框；证据框只放"本页正文没出现过"的推算值或跨页引用。
4. 大纲标了"示例数据"的，页脚免责声明写"示例数据，不作为真实统计引用"。
5. 论点条写本页 so-what，取自大纲的"结论 / 发现"原句，与标题互补、不重复标题。原句 ≤ 40 字用 26.67 px；41–48 字降到 22.67 px；49–54 字降到 21.33 px；更长就不放论点条（用 `04a`），把这句话做成正文最上方的通宽深色横条。字数含标点，按校准表实测宽度不超过 1110 px。
6. **不加整页"注："**。大纲里的"注"写成所属模块正下方的一行说明（13.33 px，不加"注："前缀也可以）；除此之外页面不写图例式说明句（"柱：…　线：…　胶囊：…"），能直接标注的就直接标注。

## 二、版面硬规则

1. **左右边界 = 标题线两端：x 35.93 与 1244.07**。任何内容元素不得越界；全宽元素（论点条、底部框架条、通栏分隔线）两端贴齐。
2. **同一行共用一条中线**：图标圆、标题、箭头、标签框、说明的垂直中心一致。
3. **同一列边缘对齐**：上下相邻模块的左右边缘落在同一条线上。
4. 正文区下界 y 672（页脚线 687.01 上方留白）。
5. 深色底上不放浅色小字；浅蓝底不放白字。
6. 颜色表达"属于哪一侧"：左/用户/现状 = 蓝系，右/策略/判断 = 红系；红色面积 ≤ 全页约 20%。砖红面板里也只给栏头、节点和重点项用实色砖红，长文和普通胶囊用中性色或描边。
7. **每页一个主视觉**。一个概念图形或主图表占正文区 45–60%，是全页视觉重心，其余模块围着它排；它可以跨过区块边界。不要用 N 个同尺寸模块等分并排作为整页结构——同类小图可以并排，但必须有一个被放大的主角，或有一个把它们串起来的大图形。
8. **分区用色块，不用细线**。大区用整栏浅底面板（浅蓝 #EEF3FA / 浅粉 #FBEFED）或深色栏头条（海军蓝 / 砖红实底白字，高 36–40）。每页正文区至少 1–2 处深色实块（栏头条、贯穿箭头带、核心圆、英雄数字底块；论点条不算）。1 px 细竖线只在面板内部辅助对齐。
9. **字号三档，拉开对比**。英雄数字每页 1–2 个，≥ 40 px（48–64 px B）；本页大纲没有数字时，改用一个"英雄关键词"（核心圆、核心色块或大字标签里的 2–6 字概念词，24–32 px）承担视觉焦点；标签 / 条目标题 17.33–21.33 px M 并着色；说明 13.33–14.67 px R。10.67 px 只用于单位、坐标轴和图内数据标签，8 px 只用于页脚。每页正文字号不超过 6 种。
10. **版面填满**。正文内容的下缘到 y 664–672；不允许底部或局部出现高于 40 px 的无内容空带。

## 三、"咨询感"从哪里来

| 做法 | 说明 |
|---|---|
| 三级标题 | 页面标题（结论句）→ 全宽论点条（so-what）→ 浅色区块标签（左边讲什么、右边讲什么） |
| 五区构图 | 区块标签 → 中央主图 + 两翼 → 远端证据框 → 底部"A ⇄ B"框架条 |
| 去卡片化 | 条目浮在版面上，用对齐、圆点虚线、弧形箭头、右箭头连成系统；卡片只留给区块标签、标签框、证据框 |
| 主视觉 + 色块分区 | 一个占半页的概念图形（漏斗、半圆辐射、圆柱阶段、同心圆层级）统领全页；浅底面板 + 深色栏头条把页面切成 2–3 个"有重量"的大区 |
| 字号对比 | 每页 1–2 个特大数字（约 60 px）与 13–14 px 说明形成强对比，缩略图上一眼看出层级 |
| 信息颗粒细 | 一条 = 图标圆 + 粗体标题 + 说明 + 标签框；证据框里允许 10.67 px 的单位 |
| 立体与质感 | 同色相渐变（海军蓝 #16365F→#2E5A94，砖红 #8E2B1D→#C0503E）；漏斗/金字塔每层左右两半深浅不同；浮起的圆和证据元素加柔和阴影 |
| 跨界与交叠 | 徽章压在节点边、图标圆压在线端、实物图压在核心圆下 —— 每页至少一处，打破格子感 |
| 图表带批注 | 阶段底色带、参考线、指向具体数据点的标注气泡、与类目对齐的同比/份额胶囊行；最关键的变化用砖红 |
| 编号串联 | 图中节点与两翼条目用相同编号（01–06），读者不用顺着连线找 |

## 四、用户确认过的具体做法（2026-10-21）

- 多栏页面**栏宽按内容分配**（图表按类目数、证据栏固定宽），不要机械等分；栏间 ~20–30 px 留白，每栏用浅底面板或栏头条界定（见二.8）；区块标签 / 栏头条与栏同宽。
- 对比页**让"行"可见**：左右两翼条目与中间指标逐行对齐，栏间细竖线、行间浅灰虚线；**不要给单元格铺底色**（会变成表格感）。
- 坐标轴能省就省：每根柱子都标了值时去掉刻度和网格线。
- 柱线组合时折线浮在柱子上方，避免标签互相遮挡。
- 直接标注代替图例：系列名写在最后一个数据点右侧。
- 竖排文字里不要放箭头（会跟着转向），轴的方向用两端的"低 / 高"小字表达。
- 底部用箭头带或框架条收束全页。

## 五、流程偏好

- 方向没确认前，先做 2–3 张代表性样张给用户看，不要大面积铺开。
- **只有用户说"可以了"的页面才算样张基线**。不要自己宣布通过，不要把未确认的页面当标准。
- 用中文沟通；每轮把新经验沉淀进本文件或 `page-patterns.md`，并提交推送。
- 以专家身份给出建议和判断，而不是让用户试错。
- **不依赖图片**：用户常用的 PPT 没有图片。主视觉、质感全部用原生形状和渐变构建，不要因为没有素材图而降低主视觉的分量。

## 六、每页自检清单（写完每页、看渲染图时都过一遍）

- [ ] 所有元素在 x 35.93–1244.07、y ≤ 672 之内；全宽元素两端贴齐
- [ ] 同行中线一致、同列边缘对齐；数字与单位不分行；无文字溢出或遮挡
- [ ] 标题是结论句；论点条与标题不重复；同一数字只出现一次
- [ ] 每个词都能在大纲里找到；推算值已记下算式（只记在交付说明里，页面上没有算式、"推算"、"据第 N 页"）
- [ ] 有一个占正文区 45–60% 的主视觉；不是 N 个等大模块平铺
- [ ] 分区靠浅底面板 / 深色栏头条；正文区至少 1–2 处深色实块
- [ ] 有 1–2 个 ≥ 40 px 的英雄数字；正文字号 ≤ 6 种；10.67 px 只出现在单位、轴和图内标签
- [ ] 至少看得到五区构图中的主要部分；内容铺到 y 664–672，没有 > 40 px 的空带；每行信息"满"
- [ ] 一页一个图标家族、同色；左蓝右红语义一致
