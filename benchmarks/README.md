## 防作弊约定（盲测）

- **生成只交给没看过参考页的子代理**。主会话负责：准备大纲副本、启动子代理、对比、评分、把差距写成通用规则。主会话一旦看过参考页，它自己生成的页面不计分。
- 给子代理的大纲放在中性路径（如 `D:\Workspace\tmp\<case>-outline.md`），不要让它从 `benchmarks/` 读。
- 子代理提示里必须写明**禁止打开或搜索**：`D:\Workspace\Sam-PPT-Skills\benchmarks\`、`模板目录` 下的任何 PPTX、`私有存档`、仓库根的 `HANDOVER.md`、仓库的 git 历史（`git log -p` / `git show`）、以及 `Sam-PPT-Bain\runs\` 下除它自己新建之外的运行目录。
- 子代理不得修改 Skill 文件、不得 commit。
- 写进 Skill 的规则只能是**通用构图 / 版面 / 技术规则**，不得出现案例的文字、数据、页面专属构图描述或页码。

## 闭环测试流程

1. 按大纲分批（每批 4 页）用盲测子代理生成。
2. `python benchmarks/tools/compare.py <RUN_DIR> <case> <首页页码>` 生成并排图，按下面的评分表打分；目标是"神似"，不是逐像素一致。
3. 把差距归纳成通用规则写进 `Sam-PPT-Bain/references/`，提交后用新的盲测子代理重跑这一批。
4. 每批最多 3 轮；达标（总分 ≥ 16 且没有 0 分项）或满 3 轮即进入下一批。分数记在 `<case>/scores.md`。

## 评分表（每项 0 / 1 / 2，满分 20）

| # | 维度 | 2 分的标准 |
|---|---|---|
| 1 | 主视觉 | 有一个统领全页的概念图形（闭环、层级、阶段推进、集合、对比结构等），一眼能看出页面在讲什么关系 |
| 2 | 分区与色块 | 页面由 2–4 个大区组成，用深色栏头条 / 箭头带 / 浅底面板 / 虚线框划分，有分量 |
| 3 | 图形语汇 | 一页用到 4 种以上构件（chevron 箭头带、编号标签、圆形节点、括号、虚线框、色块标签、立体层等），且彼此统一 |
| 4 | 连接与流向 | 用箭头、连线、编号把模块串成系统，读者知道阅读顺序 |
| 5 | 填满与密度 | 版面铺满到页脚，无大块空白；文字量与原页相当 |
| 6 | 字号层次 | 标签 / 小标题醒目，说明文字小而整齐，层级在缩略图上可辨 |
| 7 | 配色 | 海军蓝为主、砖红强调，深浅对比明显；有实色块，不是满页白底细线 |
| 8 | 文字容器化 | 关键词放进色块、圆、标签、胶囊里，而不是裸文本堆叠 |
| 9 | 精度 | 无溢出、遮挡、错位；同行同列对齐 |
| 10 | 内容完整 | 大纲本页的内容都在，没有增删改 |
