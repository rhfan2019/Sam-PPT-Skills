## 系列一到三退役（2026-10-23）

系列一到三的大纲是从同一份参考材料反推的，用户 2026-10-23 决定把这份参考材料整体转为 Skill 的风格样张（去案例化后放在 `Sam-PPT-Bain/references/approved/sample-*.png`）。从此：

- 系列一到三**不再评价质量**，分数不能作为 Skill 好坏的依据；它们仍可用来测速度、做回归（同一份输入对比耗时、检查有没有跑坏）。原评分工具包里这三个系列的标准答案随之作废。
- 质量测试改用系列九、系列十及以后的大纲。**新大纲必须独立编写，不得从提供样张的那份参考材料反推**，主题也尽量不与它重叠。
- 新大纲没有标准答案页：由用户人工评审，或由评分子代理参照 `approved/samples.md` 的风格要点打分，不做逐页比对。

## 测试方式（三角色隔离）

1. **编排会话**：把要测的大纲复制到中性路径（如 `D:\Workspace\tmp\<case>-outline.md`），按批（每批 4 页）启动生成子代理；拿到评分子代理的通用建议后改 Skill、提交推送。编排会话不打开评分工具包。
2. **生成子代理**（每轮新开）：只用 Skill 和大纲副本生成页面。会话目录必须先用 `D:\Workspace	mp	est-guard\seed.py` 准备（装好阻断读取测试工作区的钩子，2026-10-24 起）。提示里写明：不得读取仓库 git 历史、开发记录、`benchmarks/` 下除大纲副本外的内容、运行根（`D:\Workspace\Sam-PPT-Skills-Test\runs\Sam-PPT-Bain\`）下别人的运行目录，不得修改 Skill、不得 commit。
3. **评分子代理**（每轮新开）：唯一能打开评分工具包的角色；按工具包里的流程对比、打分，只回报**通用**改进建议。

每批最多 3 轮；达标线：每页总分 ≥ 16（满分 20）且没有 0 分项。
写进 Skill 的规则只能是通用构图 / 版面 / 技术规则，不得出现案例的文字、数据或页面专属构图描述。
