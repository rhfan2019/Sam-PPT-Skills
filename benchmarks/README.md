# 对照基准（benchmarks）

这里放测试 Sam-PPT-Bain 用的**标准答案**，不属于 Skill。Skill 生成时不得读取本目录（见 `Sam-PPT-Bain/SKILL.md` 的"独立性"）。

| 目录 | 内容 |
|---|---|
| `ecom-case/` | `outline.md`：从 参考模板 第一个系列（电商广告主商业价值报告，原文件第 1–12 页）反推的内容大纲，只写内容与关系、不写版式；`reference/ref-NN.png`：对应的原页渲染图 |
| `nev-case/` | 新能源汽车测试大纲与早期试点页（暂停使用） |

## 闭环测试流程

1. 用 Skill 按 `outline.md` 分批生成（每批 4 页）。
2. 每页把生成页与 `reference/ref-NN.png` 并排，按下面的评分表打分；目标是"神似"，不是逐像素一致。
3. 把差距归纳成**通用**规则写进 `Sam-PPT-Bain/references/`（不得写入本案例的文字、数据或具体构图），提交后用 Skill 重跑这一批。
4. 每批最多 3 轮；达标（总分 ≥ 16 且没有 0 分项）或满 3 轮即进入下一批。

## 评分表（每项 0 / 1 / 2，满分 20）

| # | 维度 | 2 分的标准 |
|---|---|---|
| 1 | 主视觉 | 有一个统领全页的概念图形（闭环、层级、阶段推进、集合、对比结构等），一眼能看出页面在讲什么关系 |
| 2 | 分区与色块 | 页面由 2–4 个大区组成，用深色栏头条 / 箭头带 / 浅底面板 / 虚线框划分，有分量 |
| 3 | 图形语汇 | 一页用到 4 种以上构件（chevron 箭头带、编号标签、圆形节点、括号、虚线框、色块标签、立体层等），且彼此统一 |
| 4 | 连接与流向 | 用箭头、连线、编号把模块串成系统，读者知道阅读顺序 |
| 5 | 填满与密度 | 版面铺满到页脚，无大块空白；文字量与原页相当 |
| 6 | 字号层次 | 标签 / 小标题醒目，说明文字小而整齐，层级在缩略图上可辨 |
| 7 | 配色 | 海军蓝为主、砖红强调，深浅对比明显；有实色块，不是满页白底细线 |
| 8 | 文字容器化 | 关键词放进色块、圆、标签、胶囊里，而不是裸文本堆叠 |
| 9 | 精度 | 无溢出、遮挡、错位；同行同列对齐 |
| 10 | 内容完整 | 大纲本页的内容都在，没有增删改 |
