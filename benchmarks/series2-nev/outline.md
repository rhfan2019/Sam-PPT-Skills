- 六大车企的用户认知（三项认知占比 + 品牌文化）：
  - 比亚迪：物超所值 38%；销量领先 22%；口碑优秀 10%——国潮文化
  - 特斯拉：智能科技 40%；物超所值 17%；销量领先 16%——创新领先
  - 蔚来汽车：极致服务 29%；智能科技 24%；舒适家用 10%——用户文化
  - 理想汽车：舒适家用 37%；智能科技 26%；物超所值 12%——家文化
  - 小鹏汽车：智能科技 46%；物超所值 17%；舒适家用 8%——朋友文化
  - 极氪汽车：物超所值 29%；性价比高 22%；舒适家用 16%——极客文化
- AISAS 模型（两个阶段、四个环节首尾相连）：
  - 第一阶段
    - 1.1 Attention 注意：挖掘用户内容注意点，从本品自身卖点相关出发；示例：品牌词/车型词/竞品词为主
    - 1.2 Interest 兴趣：拆解用户内容兴趣点，从购车用户关注政策入手；示例：新报价/全黑内饰/特卖会
  - 第二阶段
    - 2.1 Share 分享：结合生活分享兴趣，进行场景化种草；示例：记录生活/合拍/露营体验；新报价/全黑内饰/特卖会
    - 2.2 Action 行动：根据车型差异布局，从测评、试驾等方面促成行动；示例：高温测评/雪地测评/车主试驾
- 用户旅程覆盖的业务（左侧）：品牌传播、产品感知、新车销售、售后维修、汽车金融
- 对应的内容取向（右侧）：理性不浮夸、年轻化、"她经济"、消费体验数字化、用车场景多元化
- 总结：以推荐评测为背书，切入用户关注点增强信任感，增加行业内部的销售额；新能源用户旅程更加多元化，触点更加丰富
- 功能描述：有语音功能、有内容规范、有快捷操作

## 第 14 页｜价值链两端延展，电池全生命周期释放价值
- 汽车产业链价值变化：
  - 传统汽车价值链：制造；未来汽车价值链：研发与产品定义 + 新使用模式与未来移动出行
  - 各环节附加值（两端高、中间低，未来向右侧延展）：研发与产品定义（高，重要性提升）→ 采购物流 → 制造组装（最低）→ 产品销售 → 金融和后市场服务 → 新使用模式（共享、软件付费等）→ 未来移动出行（Robotaxi 等）

  - 电池设计：管控策略——可梯次利用化设计，调整 BMS 管控策略；特殊设计——采用易维护、拆卸及拆解的结构及连接方式
  - 电池/车辆生产：换电模式——研发换电车型、推动换电标准化；电池生产——主机厂下场参与电池生产，降低生产成本

  - 梯次利用：电池二次销售——将退役电池依次改装成储能系统/二轮车电池，进行租赁/销售
  - 材料再生：废料销售——将废旧电池制成再生材料，售给电池厂；废料换取原料——利用废旧动力电池换取新电池生产的原材料

  - Tier 1：零部件通用属性强；工艺成熟；产品更新迭代周期长；OEM 和零配件制造商研发和生产时间较为充裕
  - Tier 2—Tier N：前置生产；零部件制造商可以以较低的物流运输成本进行远距离供货；零部件通用属性强；工艺成熟；产品更新迭代周期长；OEM 和零配件制造商研发和生产时间较为充裕
