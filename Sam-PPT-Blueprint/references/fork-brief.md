主代理把下面"fork 任务说明"整段作为 prompt，只替换尖括号里的值；每个 fork 一份，页不重叠。

## fork 任务说明

---

你是从主代理分出来的改页代理（fork）。上面的对话里，ppt-master 文档、逻辑表达规范、页面分区规范、模块目录、大纲都已读过，`<RUN_DIR>/plan.md`（规划表、全稿约定、分工、推算值、审查与处理）已经写好，项目已建好，每一页都已用 `compose_page.py` 或 `start_page.py` 从参考稿模块拼好，图标已同步。**你不是主代理**：不要再开子代理，不要改别的段的页，也不要做第 5–7 步的收口。

你只负责段 <N>：**<页文件名列表>**。

- 按 plan.md 里这几页的规划改页，全稿约定是硬约束。写法照 SKILL.md 第 4 步"每页的改法"：`edit_page.py list` → 一次 `edit_page.py batch …`（先删 plan.md 列出的要删改部件，最后一条是 `sweep`）→ 补图片位和图表（按 plan.md：立体形状图保留形状、按数据改尺寸，扁平外框用原生图表模板）→ 版式补齐（`page-zoning.md` 第六节：次色单元实填、分区铺到主体带底边并对齐、画 plan.md 写的连接件、按固定样式画结论条、实心圆和实色块按 `style-baseline.json` 的阴影配方加阴影、分区标题字号不大于页面标题）→ **文字拆块、图标、浅底**（`page-zoning.md` 第七、八节：长句在标点处拆成 标签 + 短句 + 要点行，每块坐在一个载体上；图标位全部换成意思对应的图标或删掉；正文区用浅底；新部件一律用 `python scripts/add_parts.py <页> <组id> "…"` 加，不手写 SVG）→ 部件核对（`logic-diagrams.md` 第三、四节；只动关系部件，装饰保留，删单元时不要连带删底板，删部件不删载体）→ **量化自查**：`python scripts/page_metrics.py check <参考稿库> <这一页>`，按它打印的改法改到没有超出项；内容本来就少、确实补不上的项，在汇报里逐项写原因。这几页**全部写完后**，先跑 `python scripts/check_text.py <大纲> <这几页>`，列出的文字换成大纲原文或删掉（不补读法说明，图示读不懂就改图示）；再每页跑一次单页检查 `--stage page --page <页文件名>`，有阻断集中修一轮再跑一次。不跑 `check_reuse.py`（主代理在第 5 步统一跑）。不要再读文档或脚本源码，直接动笔。
- 换字只用 `edit_page.py text`（它保留段落、项目符号、分色、数字 + 单位的样式，并按框宽折行）；它报告"放不下"时，按 `page-zoning.md` 第七节的顺序处理：压缩成标签（只删字，原句写进本页说明文字，或在汇报里列出"页名｜标签 ← 原句"，由主代理写进备注）→ 拆到相邻载体 → 换模块 → 最后才 `--fit`。不要用 `place_text.py` 手工逐行摆字。
- 新画的形状（箭头、连接件、结论条、图标、补位形状）放进直接挂在根 `<svg>` 下的独立组，不要放进带 `data-pptx-object="shape"` 的导入形状组，否则导出时会丢。
- 不要新建空白 SVG；只碰你这几页的文件，不改 plan.md，不跑 `--stage final`、`stamp_native_fallbacks.py`、`export.py`、`render.ps1`。需要计划外的图标时直接加（`add_parts.py icon` 会自动同步），在汇报里列出。
- 每页开始和结束用 `date "+%Y-%m-%d %H:%M:%S"` 记时间，写进汇报。
- 写完后用中文只汇报这些：

```
页名：开始–结束；主图示一句话
压缩标签：标签 ← 原句（每条一行；没有写"无"）
删改的部件：部件 → 原含义 → 为什么删 / 改成什么；没有写"无"
推算值：<数值> = <算式>；没有写"无"
对原文的改动 / 推断：…；没有写"无"
未处理的检查告警及理由：…；没有写"无"
page_metrics 剩余超出项及理由：…；没有写"无"
新增图标：…；没有写"无"
```
